## About me / เกี่ยวกับผม

**EN** — Hi, I'm **Nameth**, a Computer Science student in Thailand. I enjoy working where data and software meet: preparing data, exploring patterns, and turning ideas into full-stack applications that solve practical problems. I care about what happens behind the interface too — data quality, validation, security, testing, and the details that make a project dependable.

**TH** — สวัสดีครับ ผม **เนเมธ** นักศึกษาสาขาวิทยาการคอมพิวเตอร์ที่สนใจทั้งงานข้อมูลและการพัฒนาซอฟต์แวร์ ผมชอบตั้งแต่การจัดการข้อมูลที่ยุ่งเหยิงให้พร้อมใช้งาน ไปจนถึงการนำไอเดียมาพัฒนาเป็นเว็บแอปที่แก้ปัญหาได้จริง และให้ความสำคัญกับคุณภาพข้อมูล การตรวจสอบความถูกต้อง ความปลอดภัย และการทดสอบระบบด้วย
